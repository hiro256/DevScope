# Naming Notes

## Current name

The project currently uses the working name `DevScope`.

No rename is planned at this stage. The project is still evolving, and the final
product scope should become clearer before committing to a new name.

## Current candidate

`ForgeSonde` is the current leading alternative name.

Intended meaning:

- `Forge` represents the software development environment or software forge.
- `Sonde` represents a probe or observation instrument.
- Together, the name reflects a tool that observes software development state rather
  than relying solely on an AI agent's self-reported status.

The name is compatible with the project's current direction:

- Plan observation from Markdown.
- Activity observation from Git.
- Evidence from build/test results.
- Optional agent integrations.
- Potential future CLI, IDE, CI, and other development-tool integrations.

## Why not rename yet

Keep `DevScope` for now because:

- The project is still early.
- Live observation is still being completed.
- Build/Test Evidence is not implemented yet.
- The proposed CLI is still experimental.
- The eventual product scope may change.
- Renaming now could create unnecessary churn.

Revisit the name after the project has demonstrated more of its intended
capabilities, especially after Evidence and the initial CLI experiment.

## Preliminary name check

`ForgeSonde` has been kept as a candidate after a preliminary availability and
conflict check.

No prominent exact-name conflict was identified during the preliminary check, but
this is not a legal or trademark clearance.

Before any public rename or package publication, check at least:

- GitHub.
- crates.io.
- PyPI.
- npm.
- Relevant domains.
- Japanese and international trademark databases.

## Decision status

This document records a naming candidate only.

`ForgeSonde` is not an adopted project name or design decision at this time.
